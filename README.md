# 공사일보 PWA v2.4 — 1인 PC/아이폰 동기화

1. Supabase 프로젝트 생성. Authentication > Users에서 본인 이메일/비밀번호 사용자 생성 (이메일 확인 완료).
2. SQL Editor에서 `schema.sql` 실행.
3. `cloud-config.js`에 Project URL과 publishable(또는 anon) key 입력. secret/service_role 키 금지.
4. 전체 폴더를 HTTPS 정적 호스팅에 업로드 (예: Netlify). PC와 아이폰 모두 **같은 HTTPS 주소**로 접속.
5. PC에서 로그인 후 **현재 기기 자료 클라우드에 올리기** 클릭. 아이폰에서는 같은 계정으로 로그인 후 **클라우드 자료 가져오기** 클릭.
6. 이후 일보 저장, 장비 등록, 사진 변경 시 업로드 예약. 다른 기기에서는 **클라우드 자료 가져오기**를 눌러 최신 자료 반영.

주의: 클라우드 계정과 배포 주소는 사용자가 직접 준비해야 합니다. 동시 편집 충돌 해결 기능은 없으며 마지막 업로드가 우선합니다. 사진을 JSON으로 함께 저장하는 초기 버전으로 사진이 많으면 업로드가 느려질 수 있습니다. 로그인은 탭 세션 단위이며 만료 시 다시 로그인해야 합니다. 이전 로컬 자료는 원래 저장했던 브라우저에서 접속하여 업로드해야 합니다. 서버 연결 전에는 기기별 로컬 저장만 됩니다. 민감한 데이터는 반드시 RLS 설정 후 사용하세요.

## v2.4 변경 사항
밴드 출력에서 [금일 작업], [명일 작업] 제목 바로 아래 업체명이 이어지도록 제목과 업체명 사이의 빈 줄을 제거했습니다.

## v2.5 직영공사 변경
- 상단 메뉴: 직영공사 월말정산, 내부 제목: 장비 및 자재 결산
- 공사일보의 `+ 업체 추가` 옆 `+ 직영` 버튼에서 직영공사 작업, 인원, 장비, 자재 입력
- 직영 장비에는 장비업체명, 장비명, 수량, 규격, 사용 구분, 적용 단가 입력
- 직영 자재에는 자재업체명, 자재명, 규격, 단위, 반입량, 사용량, 반입 단가 입력
- 직영 입력 내역은 선택 월 기준 장비 및 자재 결산 표에 자동 반영; CSV에도 포함
- 기존 장비 사용 수동 입력과 데이터는 유지하며 별도 표로 표시
- **주의**: 장비 결산은 입력 수량 × 적용 단가, 자재 결산은 반입 수량 × 적용 단가로 계산합니다. 미입력 단가는 미정산으로 표시합니다. 기존 수동 장비 내역과 직영 장비 내역에 같은 거래를 이중 입력하지 마세요.


## v2.6 직영 용역인력 정산
- 공사일보 > + 직영 > + 직영 인력 추가에서 용역회사명, 직종, 인원, 사용 구분(하루/반나절), 1인 적용 단가를 입력합니다.
- 직영공사 월말정산에서 인력·장비 및 자재 결산에 인력 비용(인원 × 적용 단가)이 자동 합산되며 CSV에도 포함됩니다.
- 이전 버전의 작업인원 숫자는 보존하지만 용역회사·단가가 없으므로 자동 정산되지 않습니다.
- 하루/반나절 단가는 해당 사용 구분의 적용 단가를 직접 입력합니다.

## v2.7 변경사항
- 명일 작업의 업체 추가 옆에 `+ 직영` 버튼을 추가했습니다.
- 명일 직영은 직영 구분명과 번호별 작업내용을 입력하고, 저장 및 밴드 출력에 `[직영]`으로 표시됩니다.
- 명일 직영은 예정 작업이므로 인력·장비·자재 결산에 반영되지 않습니다.


## v2.8 기간별 PDF 저장
공사일보 상단 **기간별 PDF 저장** 탭에서 시작일과 종료일을 선택하고, 공사 사진 포함 여부를 지정한 뒤 **선택 기간 PDF 저장 / 인쇄**를 누릅니다. 새 인쇄 창에서 프린터 대상을 **PDF로 저장**으로 선택하세요. 선택한 날짜에 해당하는 일보를 날짜순으로 한 파일에 출력하며, 일보별 페이지 구분과 사진·설명을 지원합니다. 팝업 차단 시 허용해 주세요. 기존 브라우저 저장 자료를 사용하며 클라우드 연동은 필요하지 않습니다.


## v2.9 업체별 월말결산
직영공사 월말정산에서 결산 업체 선택 및 유형 필터를 제공하며, 업체별 인력/장비/자재 합계와 미정산 건수를 확인할 수 있습니다. 업체 합계 행을 누르면 해당 업체만 표시됩니다. 월 선택/전체 기간 선택에 따라 자동 갱신됩니다. 기존 수동 장비 내역은 아래 표에 별도로 유지됩니다.


## v3.0 현장별 관리
- 상단 현장 선택에서 기존 현장 전환 및 새 현장 등록, 현장명 변경
- 현장별 공사일보 목록과 신규 일보 기본 현장 자동 지정
- 선택한 현장 기준 기간별 PDF 및 직영공사 월말정산 필터
- 기존 일보는 기록의 현장명으로 자동 분류; 기존 수동 장비 기록(현장명 없음)은 기존 용인 현장에만 표시
- 기존 브라우저 저장 키와 사진 저장소 유지. 기존 데이터 백업 권장.
